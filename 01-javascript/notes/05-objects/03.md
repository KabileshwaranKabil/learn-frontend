# 📘 Objects: Built-in Utilities & the `this` Keyword


## ✅ Object.keys()

### What it is
- Returns an **array of property names** (keys) of an object.
- Useful for iteration and transformations.

### Example
```js
const person = { name: "Kabi", age: 25, city: "Colombo" };
console.log(Object.keys(person)); // ["name", "age", "city"]
```

### Internal Notes
- Only enumerable properties are returned.
- Order is not guaranteed, but in practice most engines preserve insertion order.

---

## ✅ Object.values()

### What it is
- Returns an **array of property values**.

### Example
```js
console.log(Object.values(person)); // ["Kabi", 25, "Colombo"]
```

### Internal Notes
- Values correspond to keys returned by `Object.keys()`.
- Useful for quick access to data without worrying about property names.

---

## ✅ Object.entries()

### What it is
- Returns an **array of [key, value] pairs**.

### Example
```js
console.log(Object.entries(person));
// [["name","Kabi"], ["age",25], ["city","Colombo"]]
```

### Internal Notes
- Perfect for destructuring in loops:
```js
for (const [key, value] of Object.entries(person)) {
  console.log(key, value);
}
```

## ✅ this keyword

### What it is
- `this` refers to the **context** in which a function is executed.
- In object methods, `this` usually refers to the object itself.
- In global scope, `this` refers to the global object (`window` in browsers, `global` in Node).
- In strict mode, `this` can be `undefined`.

### Examples
```js
const person = {
  name: "Kabileshwaran",
  greet() {
    return `Hello, I am ${this.name}`;
  }
};
console.log(person.greet()); // Hello, I am Kabileshwaran
```

### Arrow Functions and `this`
```js
const person = {
  name: "Kabi",
  greet: () => `Hello, I am ${this.name}`
};
console.log(person.greet()); // "Hello, I am undefined"
```

- Arrow functions **do not bind their own `this`**; they inherit it from the surrounding scope.
- This is why arrow functions are not suitable for object methods when you need `this`.

## 📝 Practice Problems (from MDN & freeCodeCamp)

1. Use `Object.keys()` to count how many properties an object has.  
2. Write a function that takes an object and prints all values using `Object.values()`.  
3. Convert an object into an array of `[key,value]` pairs using `Object.entries()`, then rebuild it back into an object.  
4. Create an object `counter` with a method `increment` that uses `this` to update its own value.  
5. Explain why the following code prints `undefined`:
   ```js
   const obj = {
     name: "Alice",
     greet: () => console.log(this.name)
   };
   obj.greet();
   ```

---

### 🔑 Key Takeaways
- **Object.keys/values/entries** are essential for iteration and transformation.  
- **`this`** is context-sensitive: in methods it refers to the object, in arrow functions it inherits from the outer scope.  
- Mastering `this` is crucial for writing correct object methods and understanding class-based code.
