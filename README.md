This repository is my personal learning space where I document my journey in **JavaScript** and **React**.  
It contains notes, code snippets, and practice projects that reflect my progress as I build a strong foundation in frontend development.

- Gradually moved into **modern JavaScript (ES6+)** concepts such as promises, async/await, and modules.
- Transitioned into **React**, exploring components, props, state management, and hooks.
- Includes small projects and experiments that demonstrate how concepts are applied in practice.

The goal of this repository is to:
- Track my learning journey in a structured way.

- Showcase my growth from JavaScript basics to React development.
- Build a portfolio of code examples and mini-projects.

## 🚀 Technologies Covered

- **React**: Components, JSX, props, state, hooks, and project-based learning.
