# React.js Learning Journey

> A structured, project-based React learning repository focused on understanding concepts deeply rather than memorizing syntax.

---

## About

This repository documents my journey of learning React.js from scratch.

Instead of following random tutorials, this repository is organized as a structured course that emphasizes:

- Understanding how React works internally
- Building a strong mental model
- Learning through projects
- Writing detailed notes
- Practicing every concept
- Building portfolio-ready applications

The goal is not just to use React, but to understand **why** it works the way it does.

5. Practice
6. Build a mini project
